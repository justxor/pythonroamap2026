## 📐 Структура каждого этапа

Каждый файл этапа содержит:

- 🎯 Цель этапа и оценка времени
- 📘 Уроки с теорией и примерами кода
- 🛠 Упражнения с условиями
- ✅ Решения упражнений
- 📚 Бесплатные ресурсы
- ☑ Чеклист готовности

## 🎯 Правила прохождения

1. Уроки → попытка упражнения (минимум 20 минут) → разбор решения.
2. Минимум 70% времени — код руками, без копипасты.
3. Коммить свои решения в форк репозитория.
4. После каждого этапа — мини-проект из README этапа.
5. Не понятно — [t.me/pythonl](https://t.me/pythonl) или Issue в этом репо.

# 🗄️ Промпт 07 — SQL / SQLAlchemy 2.x запрос

> Используй когда: нужен сложный запрос и не уверен в синтаксисе нового API.

---

```
[CONTEXT]
PostgreSQL 16, SQLAlchemy 2.x async + asyncpg.
Модели:
[ВСТАВЬ КЛАССЫ-МОДЕЛИ ЦЕЛИКОМ]

[TASK]
Напиши запрос: <словесное описание, например «топ-10 авторов по числу постов за последние 30 дней, исключая забаненных»>.

[RULES]
- Используй стиль 2.x: select(), не legacy Query.
- async def, async with Session.
- Никаких N+1: используй selectinload() / joinedload() явно.
- Type hints на возвращаемое значение (например list[tuple[str, int]] или Sequence[User]).
- Если есть фильтр по дате — \`datetime.now(UTC) - timedelta(...)\`.
- EXPLAIN-плёвзможные узкие места — упомяни какой индекс нужен.

[LENS]
1) **SQL** — голый запрос, который ты бы написал руками.
2) **SQLAlchemy 2.x** — эквивалент через select().
3) **Индексы** — какие нужны для production-производительности.
4) **Тест** — pytest-фикстура с тестовыми данными + проверка результата.
```

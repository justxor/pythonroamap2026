# 📖 Промпт 04 — Объяснить незнакомый код

> Используй когда: пришёл в новый проект / читаешь чужую библиотеку / готовишься к code review.

---

```
[CONTEXT]
Я разработчик уровня <Junior/Middle/Senior>.
Изучаю проект: <короткое описание>
Знаю: <Python, FastAPI, …>
Не знаю / слабо: <SQLAlchemy 2.x async / asyncio internals / …>

[CODE]
[ВСТАВЬ КОД]

[TASK]
Объясни этот код так, чтобы я мог потом его модифицировать.

[RULES]
- Без воды. Технически точно.
- Адаптируй под мой уровень (см. выше).
- Если используется специфичный паттерн/идиома Python — назови его и дай 1 ссылку на доку.
- Подсвети неочевидные места (gotchas).

[LENS]
1) **Высокоуровнево:** что этот код делает в 2-3 предложениях.
2) **Построчно:** разбор ключевых блоков (не каждой строки — только тех, где есть смысл).
3) **Зависимости:** какие модули/функции из проекта он использует.
4) **Опасные места:** где можно сломать при модификации.
5) **Тест-кейсы:** какие сценарии стоит проверить прежде, чем менять.
```

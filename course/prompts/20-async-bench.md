# 20 — Async benchmark

> Промпт для сравнения asyncio / uvloop / nogil-threads / processes.

---

## Промпт

```
Ты — Python performance engineer.
Спроектируй бенчмарк для сравнения 4 подходов к параллелизму в Python 3.13+:

1. asyncio (default loop)
2. asyncio + uvloop
3. threading на free-threaded build (python3.13t, GIL off)
4. multiprocessing (ProcessPoolExecutor)

Задача: {опиши здесь, напр. "10 000 GET-запросов на httpbin", или "сжать 1 000 JSON‘ов в gzip"}

Требования:
- Приведи полный код для каждого подхода (1 файл на вариант).
- Используй одну и ту же функцию payload во всех.
- Тайминг: `time.perf_counter()` обёртка.
- Warmup на 5% задач, потом измерение.
- Собери метрики: total_time, throughput (op/s), CPU%, RSS peak.
- Приведи ожидаемые результаты и объясни, почему.
- Дай рекомендацию: когда какой подход выбрать.

Формат ответа:
1. Дизайн-таблица (подход → ожидаемая производительность).
2. 4 файла с кодом.
3. Баш-скрипт запуска всех вариантов подряд.
4. Анализ и рекомендации.
```

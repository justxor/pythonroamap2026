# 🎯 Промпт: 20 идей фичей для моей задачи

> Цель: быстро получить брейншторм идей по feature engineering + готовый код на polars.

## Шаблон

```text
# Роль
Ты ML-практик с 10-летним опытом, выигрывавший Kaggle.

# Контекст
- Домен: <например, банковский фрод>
- Цель: предсказать <target>
- Данные в polars.DataFrame:
  - Колонки (dtype): <список>
  - Пример 5 строк: <head>

# Задача
Предложи 20 идей фичей, разбитых по категориям:
1. Прямые преобразования (log, ratio, bucket)
2. Временные (lag, rolling, time-since-last-event)
3. Агрегаты по группам (user, merchant)
4. Интеракции (произведение, разность)
5. Target/CatBoost encoding
6. Бизнес-логика (доменные)

Для каждой идеи укажи:
- Название
- Гипотеза (почему должно помочь)
- Код на polars (1–3 строки)
- Риск утечки (low / mid / high)

# Ограничения
- Отмечай high-risk утечки
- Предпочитай код, выполнимый в lazy-режиме polars (.lazy() ... .collect())
- Никакого .apply() / for-циклов
```

## Советы

- Требуй идеи ранжировать по ожидаемому эффекту.
- Проверяй риск утечки: всё, что использует target или future-events — это красный флаг.
- Не все идеи полезны — валидируй через CV.

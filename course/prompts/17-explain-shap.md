# 🎯 Промпт: объясни мне SHAP-результаты

> Цель: подготовить бизнес-интерпретацию по SHAP-отчёту модели.

## Шаблон

```text
# Роль
Ты ML-engineer, объясняешь результаты модели продакт менеджеру без технического бэкграунда.

# Контекст
- Задача: <описание бизнес-задачи>
- Модель: <LightGBM / CatBoost / ...>
- Метрика на holdout: <AUC / F1 / ...>
- Top-10 фичей по |SHAP|:
  1. feature_name (mean |SHAP| = X.XX)
  2. ...
- 3 примера предсказаний (low/mid/high score) с их SHAP-вкладами

# Задача
1. Объясни простыми словами, как для каждой top-фичи изменение в ней влияет на прогноз.
2. Разбери 3 примера: почему вышли такие скоры.
3. Найди 2–3 counter-intuitive паттерна и предложи гипотезы.
4. Сформулируй 3 action-items для бизнеса.
5. Предостережения: что в этой интерпретации нельзя путать с причинностью.

# Формат
- Markdown, списки
- Каждый блок — заголовок + 1–2 предложения
- Никакого жаргона в стиле «SHAP value» прямым текстом — заменяй на «вклад фактора»
```

## Советы

- Давай модели осязаемые значения, а не картинки. Для визуализации выгружай PNG отдельно.
- Для каждой фичи добавь направление влияния (+ / −).
- Проси LLM прямо предупреждать о потенциальных утечках и смещениях.

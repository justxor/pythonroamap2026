# ♻️ Промпт 03 — Рефакторинг без изменения поведения

> Используй когда: код работает, но грязный. Нужно почистить, не сломав ничего.

---

```
[CONTEXT]
Python 3.13, стек: <твой стек>.
Файл: <путь>
Тесты на этот модуль: <путь к тестам или «нет»>

[CODE]
[ВСТАВЬ КОД]

[TASK]
Отрефактори этот код. Поведение НЕ должно измениться — все тесты должны остаться зелёными.

[RULES]
- Никаких функциональных изменений. Только структура, имена, разбиение.
- Маленькие шаги: один тип улучшения за один шаг.
- Сохрани публичный интерфейс (сигнатуры функций, имена классов).
- Прогоняй мысленно тесты после каждого шага.
- Применяй:
  * Extract function / Inline variable / Rename.
  * Замена if-elif цепочек на dict-dispatch или match-case.
  * Замена циклов на comprehensions/генераторы где это понятнее.
  * Декомпозиция длинных функций (> 30 строк).
  * Type hints везде, где их нет.
  * Замена print → structlog.
- НЕ применяй (без отдельной просьбы):
  * Смену библиотек.
  * Перевод sync ↔ async.
  * Изменение архитектуры (см. промпт 11).

[LENS]
1) Сначала: список улучшений списком (что → почему).
2) Жду моего «ок».
3) Потом код целиком, новой версией.
4) В конце — diff-summary: что изменилось.
```

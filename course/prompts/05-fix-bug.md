# 🐛 Промпт 05 — Починить баг по traceback

> Используй когда: упало в production / тесты красные / поведение не такое.

---

```
[CONTEXT]
Python 3.13, стек: <твой стек>.
Что должно происходить: <ожидаемое поведение>
Что происходит: <фактическое поведение>
Когда сломалось: <всегда / иногда / после релиза X / при условии Y>

[TRACEBACK]
[ВСТАВЬ ПОЛНЫЙ TRACEBACK / ЛОГИ / СКРИНШОТ ОШИБКИ ТЕКСТОМ]

[RELEVANT CODE]
[ВСТАВЬ КОД ФУНКЦИЙ ИЗ TRACEBACK]

[TASK]
Найди причину и предложи минимальное исправление.

[RULES]
- НЕ предлагай «попробуй переустановить зависимости» без оснований.
- Сначала диагноз, потом лечение.
- Минимальный патч — никаких сторонних рефакторингов.
- Обязательно: тест, который воспроизводит баг и зелёный после фикса.
- Если причина в стороннем коде/баге библиотеки — укажи issue/PR в их репозитории.

[LENS]
1) **Диагноз:** в одном абзаце — что и почему сломалось.
2) **Reproduction:** минимальный сниппет / тест, который падает.
3) **Fix:** код-патч (diff или новая версия функции).
4) **Test:** pytest-тест, который теперь зелёный.
5) **Регрессионный риск:** что ещё может сломаться.
```
